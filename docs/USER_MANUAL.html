1. System Overview & Architecture

CNAT Screen Recorder is a high-performance desktop application engineered for seamless screen recording, tutorial creation, presentation streaming, and video production. Built with Python 3.10+ and PyQt6, it leverages direct Windows APIs (DXGI / DirectShow / WASAPI) for near-zero latency capture.

🎥 4K Ultra HD Engine

Fluid 3840×2160 capture at 60/120 FPS with Lanczos hardware scaling and zero dropped frames.

🎙️ Multi-Track Audio

Simultaneous capture of WASAPI system sound, dedicated studio microphone, and webcam microphone.

📷 Studio Presenter Suite

Floating PiP bubbles, 5 framing shapes, 6 color filters, and full-screen presenter cam mode.

⚡ Hardware GPU Accel

Automatic detection of NVIDIA NVENC, Intel QuickSync (QSV), AMD AMF, and CPU libx264 fallback.

2. Quick Start & Creator Defaults

Upon launch, the application loads with the optimized Creator Profile:

  • 🔊 System Audio: Unchecked (Off) by default to avoid accidental notification chimes.
  • 🎙️ Microphone: Checked (On) by default, automatically prioritizing dedicated USB mics (e.g. JBL Commercial CSUM10).
  • 🔇 Noise Reduction: 0% (Off) by default.
  • 📷 Webcam PiP: Checked (On) by default, auto-detecting Iriun Webcam with ⭕ Circle Bubble framing shape.
  • 🎙️ Webcam Audio: Unchecked (Off) by default to prevent room feedback.
  • 🎯 Resolution & Quality: 4K Ultra HD (3840x2160) & 4K Ultra Master (60 Mbps).
💡 3-Step Recording Workflow:
  1. Select your capture mode (Full Screen or Social Media Preset).
  2. Press F9 to begin after the 3-second visual countdown.
  3. Press F9 again to finish and preview/trim your video instantly.

4. Multi-Source Audio Engine & Mixing

CNAT Screen Recorder incorporates an advanced audio pipeline capable of recording multiple streams simultaneously with zero phase distortion:

  • System Loopback (WASAPI): Captures internal system sounds, video calls, games, and web media cleanly.
  • Microphone Input: Studio-grade vocal recording with auto-detection for USB hardware microphones.
  • Webcam Audio: Direct capture from camera array microphones.
  • Live VU Meters: Real-time graphical level meters for immediate visual monitoring.

5. Real-Time AI Noise Suppression

The integrated noise suppression engine filters background noise in real time using frequency-domain spectral subtraction and downward dynamic gating:

  • 0% (Off): Pure studio bypass.
  • 1% – 35% (Subtle): Removes subtle computer fan noise and electrical hum while preserving voice richness.
  • 36% – 70% (Balanced): Eliminates room reverberation, air conditioner noise, and outside traffic.
  • 71% – 100% (Aggressive): High-attenuation suppression for noisy shared environments.

11. Diagnostics & Frequently Asked Questions (FAQs)

Q: Where are recordings saved?
A: By default, in C:\Users\<Username>\Videos\CNATRecordings\. You can change this in the Settings (⚙️) dialog.

Q: How do I use my mobile phone as a 4K webcam?
A: Install Iriun Webcam on both phone and PC. Ensure both devices are on the same Wi-Fi network (or connected via USB). CNAT Screen Recorder automatically selects Iriun Webcam.
